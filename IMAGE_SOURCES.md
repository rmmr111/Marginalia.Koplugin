# Image Sources and Redistribution Notes

This list documents the sources of the 249 distributed ornament files in this version of Marginalia. **Not every image is CC0**; the per-file origin and conditions are recorded in `IMAGE_MANIFEST.csv`.

- **Rapier (76 SVG files)** — Rapier states that its vector tracings are released under CC0 1.0: https://rapier.website/gallery#borders . Original source materials may have separate historical provenance.
- **Hellmouth (157 PNG files)** — Transparent cutouts of medieval manuscript illustrations. The compiler publicly permits using these images for whatever purpose; this is broad permission, **not an express CC0 dedication**: https://hell-mouth.neocities.org/marginalia . The original manuscripts' sources remain relevant.
- **Rawpixel public-domain collection (3 JPG files)** — Items 8995292, 8998091 and 9000427, identified as public domain/CC0: https://www.rawpixel.com/public-domain . Individual URLs are in `IMAGE_MANIFEST.csv`.
- **Wikimedia Commons / Openclipart (13 SVG files)** — Exact sources and statuses are in `IMAGE_MANIFEST.csv`. Includes historical public-domain works and Openclipart works whose original SVG metadata indicates public-domain/CC0.
